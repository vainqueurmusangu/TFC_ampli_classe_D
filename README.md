# Simulation LTspice — Amplificateur de Puissance Audio Classe D 300W BTL

Ce répertoire contient les fichiers de simulation LTspice associés au travail de fin de cycle (TFC) sur la conception d'un amplificateur audio de puissance en Classe D (300W sous 4Ω) en pont complet (BTL).

## 🚀 Préréquis
- **LTspice** (version 26.0.1 ou supérieure).
- Aucun modèle externe n'est requis (utilisation exclusive des composants natifs ADI/LT).

## 📁 Contenu du dépôt
- `Draft1.asc` : Schéma complet de l'amplificateur (modulateur, étage de puissance, filtre LC).
- `README.md` : Présentation du projet et instructions.
